## Omyaru Browser v1.0.7

### 공통 개선 (iOS build 116 · Android versionCode 84)
- **새 창(팝업 / `target="_blank"`) 탭 뒤로가기 지원**: 새 창으로 열린 탭에서도 뒤로가기 버튼 및 왼쪽→오른쪽 뒤로가기 스와이프(Android 시스템 뒤로가기 포함)가 활성화되며, 뒤로가기 시 팝업 탭을 닫고 원래 보던 부모 탭으로 즉시 복귀합니다.
- **탭 목록에서 닫기 시 원래 탭 선택**: 탭 목록에서 새 창 탭을 닫을 때 맨 아래 탭으로 튀지 않고, 해당 창을 열었던 원래 부모 탭(부모가 없으면 인접 탭)이 자동으로 선택됩니다.
- **책장 사진 순서 정밀 정렬 (오래된 사진 위 → 최근 사진 아래)**: 책장 목록, 공유 저장소 병합, 연속 이미지 추가, Google Drive 동기화 전 과정에서 `createdAt` 시간 오름차순(초/밀리초 자동 정규화)으로 정렬하도록 통일해 기기 간 동기화 후 순서가 뒤섞이던 문제를 해결했습니다.
