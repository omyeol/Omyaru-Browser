## Omyaru Browser v1.0.0

Omyaru Browser의 첫 번째 정식 메이저 버전 **v1.0.0**입니다. iOS · Android · Windows(PC) 전 플랫폼의 버전 체계를 `1.0.0`으로 통합하고 새로운 공식 브랜드 아이콘과 Safari 수준의 120fps 인터랙션을 완성했습니다.

### 주요 변경 사항

#### 1. 신규 공식 아이콘 & 전 플랫폼 v1.0.0 통합
- **Pearl 3D `"O"` 리본 공식 아이콘 적용**: iOS(1024×1024 AppIcon · AltStore/LiveContainer), Android(Adaptive Icon + 전 해상도 mipmap), Windows PC(다중 해상도 `.ico` 실행 파일 및 창 아이콘) 전 플랫폼에 일괄 적용
- **전 플랫폼 v1.0.0 버전 통합**: iOS `v1.0.0 (build 109)`, Android `v1.0.0 (versionCode 78)`, Windows PC `v1.0.0`

#### 2. 앱 · 책장 잠금 Face ID 즉시 해제 (iOS)
- **Face ID 인식 후 1초 지연 완전 해결**: Face ID 인증 도중 및 인증 성공 직후 `scenePhase`가 `.inactive → .active`로 복귀하는 구간에서 잠금 아이콘 프라이버시 실드가 불필요하게 뜨던 문제를 수정해, 얼굴 인식과 동시에 0ms 지연으로 브라우저·책장이 즉시 열리도록 개선 (앱 전환기·백그라운드 프라이버시 보호 실드는 기존과 동일하게 유지)

#### 3. Safari 스타일 120fps Hero Zoom 전환 & 상황별 탭 애니메이션
- **120fps GPU 포털 Hero Zoom 모핑**: 웹 서핑 ↔ 탭 목록 전환 시 `WKWebView`를 그대로 유지한 채 GPU 포털을 모핑하는 Safari 스타일 확대/축소 애니메이션 적용 (iOS · PC · Android 공통)
- **상황별 탭 열기·닫기 애니메이션 (iOS)**:
  - **새 탭 추가(`+`)**: 탭 목록 맨 아래 생성 + 생성 슬롯 위치(우측 하단/좌측 하단/중앙 히어로)에서 자연스럽게 피어오르는 블룸 확장
  - **중간 탭 닫기**: 닫히는 카드는 뒤 레이어에서 제자리 축소·페이드, 뒤쪽 카드는 좌측·대각선 상단으로 부드럽게 2D 리플로우
  - **맨 끝 탭 닫기**: 행 유지 시 제자리 축소·페이드, 마지막 행 축소 시 그리드 높이와 스크롤이 스프링으로 부드럽게 자동 이동
- **상·하단 버튼 겹침 자동 회피 스크롤 (iOS)**: 탭 목록 스크롤 위치를 기억하고, 선택한 탭이 상단/하단 버튼과 겹쳐 있던 경우 탭 목록으로 돌아올 때 버튼과 겹치지 않도록 자동 보정
- **전환 안정성 전면 해결**: 59pt 상하 튐, 스크롤 누적 이동, 콜드 탭 깜빡임, 검은 썸네일 덮어쓰기, 백드롭 흰색 비침, 카드 비율 왜곡 수정

#### 4. URL 필드 섬 · 가우시안 블러 · 설정 UI
- **Safari 동일 높이 축소 URL 필드 & 좌우 빈 공간 터치 확장**: 연속 Liquid Glass 모핑 URL 필드 높이를 Safari와 동일하게 맞추고, 축소 시 좌우 빈 공간을 탭해도 URL 필드가 즉시 확장되도록 개선
- **상단 다중 가우시안 블러 & 하단 블러 제거**: 상단 스크롤 영역을 부드러운 다중 밴드 가우시안 흐림(`ProgressiveGaussianBlurView`)으로 업그레이드하고 하단 블러를 제거
- **도구모음·설정 정리**: 페이지 도구·툴바 버튼 편집을 설정 전용으로 통합, VPN·잠금 등 모든 하위 설정이 설정 창 안에서 열리고 완료 시 복귀, 설정 다크 모드 수정, Liquid Glass OFF 시 탭 목록 단색 UI 적용

#### 5. 브라우징 & 양방향 동기화
- **프로필 색상 활성 탭 테두리 · 상단 정렬 썸네일 · 당겨서 새로고침**: 활성 탭에 그룹 프로필 색상 테두리 적용, 썸네일 상단 정렬(`TopAlignedFillImage`), 상단 오버스크롤 색상 동기화 및 네이티브 당겨서 새로고침 스피너 추가
- **PC · Android · iOS 양방향 CRDT 동기화**: 탭·탭 그룹·프로필 실시간 양방향 동기화 및 Google Drive 공용 책장 병렬 동기화
