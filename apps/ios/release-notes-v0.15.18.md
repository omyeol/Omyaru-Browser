## Omyaru Browser v0.15.18

### 주요 변경 사항

#### 1. Safari 스타일 120fps Hero Zoom 전환 & 탭 목록 애니메이션
- **120fps GPU 포털 Hero Zoom 모핑**: 웹 서핑 ↔ 탭 목록 전환 시 `WKWebView`를 그대로 유지한 채 GPU 포털을 모핑하는 Safari 스타일 확대/축소 애니메이션 적용 (iOS / PC / Android 공통)
- **상황별 탭 열기·닫기 애니메이션 (iOS)**:
  - **새 탭 추가(`+`)**: 탭 목록 맨 아래에 생성되며 생성될 슬롯 위치(우측 하단/좌측 하단/중앙 히어로)에서 자연스럽게 피어오르는 블룸 확장 애니메이션 적용
  - **중간 탭 닫기**: 닫힌 카드는 뒤 레이어에서 제자리 축소·페이드되고, 뒤쪽 카드들이 좌측·대각선 상단으로 부드럽게 2D 리플로우
  - **맨 끝 탭 닫기**: 행 수가 유지될 때는 제자리 축소·페이드, 마지막 행이 사라질 때는 그리드 높이와 스크롤이 스프링으로 부드럽게 축소 이동
- **상·하단 버튼 겹침 자동 회피 스크롤 (iOS)**: 탭 목록 스크롤 위치를 기억하고, 선택한 탭이 상단/하단 플로팅 버튼과 겹쳐 있던 경우 탭 목록으로 돌아올 때 버튼과 겹치지 않는 위치로 자동 조정
- **안정성 수정 (iOS)**: 탭 전환·목록 이동 시 발생하던 59pt 상하 튐, 스크롤 위치 누적 이동, 콜드 탭 깜빡임, 비동기 스냅샷의 검은 화면 덮어쓰기, 백드롭 흰색 비침 및 카드 비율 왜곡 전면 수정

#### 2. URL 필드 섬 · 툴바 · 설정 UI 개선
- **연속 Liquid Glass URL 필드 모핑**: 스크롤 축소/확장 시 URL 필드 섬이 끊김 없이 연속 모핑되도록 개선하고 하단 섬 높이 최적화
- **축소 URL 필드 좌우 빈 공간 터치 확장**: URL 필드가 작아졌을 때 좌우 빈 공간을 터치해도 URL 필드를 누른 것과 동일하게 확장되도록 개선
- **도구모음·페이지 도구 편집 통합**: 페이지 도구 편집 및 툴바 버튼 편집을 설정 화면 전용으로 통합하고 최적화
- **설정 내부 화면 전환 & 다크 모드 수정**: VPN·앱/책장 잠금 등 모든 하위 설정이 설정 창 안에서 열리고 완료 시 설정 창으로 복귀하도록 개선, 설정 화면 다크 모드 정상 적용
- **Liquid Glass OFF 단색 UI**: Liquid Glass를 끈 상태에서는 탭 목록 버튼과 바가 그라데이션 없는 깔끔한 단색으로 표시

#### 3. 브라우징 & 동기화 기능 개선
- **프로필 색상 활성 탭 테두리 & 상단 정렬 썸네일**: 탭 목록에서 현재 선택된 탭의 테두리를 해당 탭 그룹의 프로필 색상으로 강조하고, 모든 탭 썸네일이 중간이 아닌 웹페이지 최상단부터 표시되도록 수정
- **상단 오버스크롤 배경색 동기화 & 당겨서 새로고침**: 웹페이지 최상단 오버스크롤 영역 색상을 페이지 상단 색상과 일치시키고 네이티브 `UIRefreshControl` 스피너 새로고침 추가
- **롱프레스 컨텍스트 메뉴 & 그룹 캐러셀**: 탭 길게 눌러 들어 올리기(드래그 순서 변경 / 손을 떼면 제자리 컨텍스트 메뉴) 및 하단 그룹 캐러셀 스와이프 개선
- **PC · Android · iOS 양방향 동기화 & 책장 잠금**: CRDT 기반 탭·탭 그룹·프로필 양방향 동기화, 책장 전용 잠금(타임아웃/기기 잠금 연동), 백그라운드 Google Drive 동기화 UI 정리
