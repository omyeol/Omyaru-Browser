## Omyaru Browser v1.0.3 (iOS · Android)

URL 필드 섬이 커졌다 작아졌다 할 때 간헐적으로 1프레임에 갑자기 튀며 커지거나 작아지던 현상을 근본적으로 해결한 업데이트입니다.

### 주요 변경 사항

- **URL 필드 섬 확대/축소 급격한 튐 현상 완전 수정 (iOS · Android)**
  - **120Hz 물리 스프링 엔진 도입**: iOS(`CADisplayLink`)와 Android(`Choreographer`)에 2-서브스텝 연속 스프링 엔진을 적용해, SwiftUI `ObservableObject` 트랜잭션 충돌이나 빠른 단일 프레임 스크롤 변화에도 1프레임 급격한 크기 점프가 수학적으로 발생하지 않도록 개선했습니다.
  - **커밋 전환 보호 & 연속 시드**: 축소/확장 임계값을 통과해 커밋 애니메이션이 진행 중일 때 손가락 잔여 스크롤 이벤트가 애니메이션을 덮어쓰지 못하도록 잠금 처리하고, 전환 도중 다시 화면을 터치할 때 현재 시각적 진행률에서 연속적으로 이어받도록 수정했습니다.
  - **구조적 뷰 재구성 제거 (iOS)**: 축소 시 좌우 빈 공간 터치 영역을 `ZStack`에서 조건부 삽입/제거하지 않고 상시 마운트(`.allowsHitTesting`) 방식으로 전환해 확장/축소 경계에서 프레임 끊김이 발생하지 않도록 정리했습니다.
