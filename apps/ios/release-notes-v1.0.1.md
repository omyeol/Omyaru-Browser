## Omyaru Browser v1.0.1 (iOS · Android)

모바일(iOS · Android) URL 필드 섬의 곡률과 도메인 표시 방식을 Safari와 동일하게 개선한 업데이트입니다.

### 주요 변경 사항

- **Safari 동일 URL 필드 섬 곡률 적용 (iOS · Android)**
  - 확장 상태 URL 필드 섬의 외곽 모서리 곡률을 Safari와 동일하게 맞추어(iOS `43pt` 연속 곡률, Android `40dp` 곡률 및 내부 주소 캡슐 `24dp` 정렬) Liquid Glass ON/OFF 모두에서 화면 모서리·내부 주소창과 자연스럽게 동심원을 이루도록 개선했습니다.
- **설정: '주소창에 도메인만 표시' 옵션 추가 (iOS · Android)**
  - `설정 > 화면 및 모양`에 **주소창에 도메인만 표시** 옵션을 추가했습니다.
  - 옵션을 켜면 `https://m.naver.com/어쩌고저쩌고`, `https://www.google.com/?zx=...` 같은 주소도 Safari처럼 **`naver.com`**, **`google.com`**으로 간결하게 중앙 표시되며, 주소창을 탭해 편집할 때는 기존처럼 전체 URL을 편집할 수 있습니다.
- **축소 URL 필드 섬 항상 도메인만 표시 (iOS · Android)**
  - **주소창에 도메인만 표시** 옵션을 켜지 않아도, 스크롤로 URL 필드 섬이 작아졌을 때는 페이지 제목이나 긴 주소 대신 항상 **`naver.com`**, **`namu.wiki`** 같은 간략한 도메인만 표시되도록 통일했습니다.
