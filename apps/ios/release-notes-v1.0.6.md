## Omyaru Browser v1.0.6

### iOS (build 115)
- **URL 필드 자동 전체 선택 및 시스템 편집 메뉴**: URL 필드를 누르면 키보드가 열리며 전체 URL이 자동으로 선택되어 바로 입력·검색할 수 있고, 전체 선택된 URL을 누르면 iOS 기본 `오려두기 / 복사하기 / 붙여넣기` 메뉴가 바로 표시됩니다. URL 섬 바깥 영역을 터치하면 키보드가 깔끔하게 닫힙니다.

### Android (versionCode 83)
- **URL 필드 자동 전체 선택 및 편집 메뉴**: URL 필드를 눌러 키보드가 열릴 때 전체 URL이 풀리지 않고 정확히 전체 선택되며, 전체 선택된 URL을 누르면 Android 기본 `잘라내기 / 복사 / 붙여넣기` 플로팅 메뉴가 표시됩니다.
- **좌/우 엣지 뒤로가기·앞으로가기 스와이프 제스처**: 왼쪽 끝에서 오른쪽으로 밀어 뒤로가기, 오른쪽 끝에서 왼쪽으로 밀어 앞으로가기 제스처(플로팅 화살표 인디케이터 + 햅틱 피드백)를 추가하고, 우측 빠른 스크롤바의 비표시 상태 터치 가로채기를 제거했습니다.
- **축소된 URL 필드 좌우 빈공간 터치 확장**: URL 필드가 작아졌을 때 좌우 빈공간을 터치해도 URL 필드가 다시 커지도록 iOS와 동일하게 개선했습니다.
- **하단 사이트 고정 UI 겹침 방지 강화**: GeckoView `setDynamicToolbarMaxHeight` + `setVerticalClipping` 연동을 보강해 사이트 하단 고정 바가 URL 필드 섬에 가리지 않도록 개선했습니다.
