## Omyaru Browser v1.0.2 (iOS · Android)

Safari의 URL 필드 섬 외곽 곡률, 축소 알약 크기, 그리고 스크롤 연동 인터랙티브 모핑 애니메이션을 정밀하게 일치시킨 업데이트입니다.

### 주요 변경 사항

- **Safari 동일 비대칭 동심원 URL 필드 섬 곡률 (iOS · Android)**
  - Safari 실측과 동일하게 상단(`38.5pt`)과 하단(`45.5pt`) 모서리 곡률을 분리 적용(`SafariIslandShape`, Android 상단 `37dp` · 하단 `44dp`)하고 좌우 여백을 `12pt/12dp`로 정렬해 기기 화면 모서리 및 내부 주소 캡슐과 완벽한 동심원을 이루도록 개선했습니다.
- **Safari 동일 도메인 맞춤 축소 URL 알약 폭 (iOS · Android)**
  - 기존 고정 넓이(`186pt` / `147dp`)로 좌우가 길던 축소 URL 필드를 도메인 텍스트 길이에 딱 맞는 컴팩트 크기(`naver.com` 기준 약 `93pt × 31pt` / Android `94dp × 34dp`, 최소 `82pt` ~ 최대 `156pt`)로 개선했습니다.
- **Safari 스타일 스크롤 연동 인터랙티브 모핑 & 임계값 (iOS · Android)**
  - **손가락 1:1 연동 축소/복원**: 페이지를 살짝 아래로 내렸다 다시 올리면 임계값(`36pt`) 이전 구간에서 URL 필드 섬이 손가락 움직임을 1:1로 따라 부드럽게 줄어들었다 다시 늘어나며, 손을 떼면 원래 크기로 탄력 있게 복원됩니다.
  - **축소 상태 스크롤 업 예고 팽창**: 축소 상태에서 살짝 위로 스크롤할 때 `18pt` 데드존을 지나면 컴팩트 알약이 부드럽게 넓어지며 확장을 예고하고, `80pt` 이상 스크롤하거나 빠른 상향 플릭·페이지 최상단 도달 시 전체 섬으로 자연스럽게 펼쳐집니다.
